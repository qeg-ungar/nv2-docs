# PID Heater

The science box temperature is actively stabilized using an Arduino-based PID heater system.
Temperature stability reduces thermal drift of the diamond sample and optical mounts, which
is critical for long-duration experiments.

## Components

- **Arduino** — microcontroller running the PID control loop
- **Heater element** — resistive heater mounted inside the science box
- **Temperature sensor** — thermistor or thermocouple for feedback
- **Power supply** — drives the heater element
